ไฟล์สำหรับเว็บที่ deploy จาก GitHub repository root:
- index.html
- app.js

- config.js

มี 6 โหมดเกมและ 4 สไตล์ รวมถึงปุ่มสุ่มหัวข้อช่วยคิด และซิงก์การตั้งค่าผ่านห้อง Supabase

วิธีอัปเดต: แตก ZIP บน iPhone แล้วเปิด GitHub repository ของตัวเอง จากนั้นเข้าไฟล์ index.html, app.js, style.css และ config.js ทีละไฟล์ แล้วใช้ปุ่ม Edit (ดินสอ) วางเนื้อหาไฟล์ที่ตรงกันจาก ZIP และ Commit changes. หากเว็บเดิมมี config.js ที่ใช้งานได้ ให้เก็บค่าเดิมไว้ ไม่ต้องเปลี่ยนค่าการเชื่อมต่อ

หมายเหตุ: ยังต้องทดสอบกับห้องจริงสองเครื่องหลัง deploy; การเปลี่ยนโหมด/สไตล์ให้เลือกได้โดยเจ้าของห้อง และเก็บไว้ในค่าห้องเดิม
